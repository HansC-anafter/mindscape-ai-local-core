# Instagram Week 1 Calendar

本文件為 deliverable `規劃 7 天 IG post / reel 的內容節奏、CTA 與產出順序` 的正式定稿，承接 [persona_operating_system.md](/Users/shock/Projects_local/workspace/mindscape-ai-local-core/persona_operating_system.md) 的品牌角色規格，並與 [reel_hook_bank.md](/Users/shock/Projects_local/workspace/mindscape-ai-local-core/reel_hook_bank.md) 的 Reel 開場口徑對齊。首週任務不是成交，而是讓受眾快速辨認這個品牌的角色、節奏與可信度，建立「這個帳號懂我，而且不會推著我跑」的第一印象。

## 1. 文件任務

| 項目 | 定義 |

| Deliverable | D2 `第一週 Instagram 啟動週曆` |
| 目標 | 規劃 `7` 天內容節奏、每日主 CTA、實際產出順序 |
| 核心受眾 | 高壓、高責任感、休息了卻不一定恢復的創作者與知識工作者 |
| 品牌任務 | `先命名狀態 -> 再翻譯機制 -> 再給一個低摩擦起點 -> 再邀請互動` |

## 2. 首週啟動策略

- **內容遞進**：`角色進場 -> 狀態辨識 -> 拆掉自責 -> 提供一步 -> 放大共鳴 -> 自我檢查 -> 系列收束`
- **互動分工**：`追蹤` 負責建立系列感，`收藏` 負責沉澱工具價值，`留言` 負責收語料，`分享` 負責放大共鳴
- **節奏原則**：每篇只完成一個任務，不同一天分別承擔「認識」、「辨識」、「理解」、「開始」與「回來看」
- **表達原則**：每則內容都先讓人感到被理解，再進入方法；不恐嚇、不診斷、不承諾結果

## 4. 每日執行 Brief

### Day 1｜角色進場 Reel

- **任務**：建立品牌第一印象，讓受眾知道這個帳號不是來教訓他，而是來幫他命名狀態
- **建議 hook**：優先使用 `Hook 01` 或 `Hook 04`
- **內容骨架**：命中情境 `你不是不會休息` -> 翻譯機制 `系統還沒退場` -> 說清楚這個帳號會怎麼幫你
- **主 CTA**：`如果你想把這件事看得更清楚，先追蹤。`
- **產出物**：短版腳本、字幕稿、封面標題、口播錄影
- **執行提醒**：這支只做角色辨識，不提前塞進完整教學

### Day 2｜辨識清單 Carousel

- **任務**：交付第一份讓受眾願意收藏的辨識工具
- **頁數建議**：`5-6` 頁
- **內容骨架**：封面提問 -> `3` 個日常訊號 -> 一句正常化翻譯 -> 收藏 CTA
- **主 CTA**：`如果這張清單像在說你，先收藏。`
- **產出物**：封面文案、每頁短句、最後一頁 CTA
- **執行提醒**：每頁只講一個訊號，做成工具卡，不做成長文貼

### Day 3｜拆自責 Reel

- **任務**：把「我是不是不夠自律」改寫成更能被理解的狀態訊號
- **建議 hook**：優先使用 `Hook 05`，備選 `Hook 06`
- **內容骨架**：拆掉誤解 `不是自制力差` -> 補一句可能機制 -> 丟一個留言問題
- **主 CTA**：`你最常停不下來的是哪個時段？留言告訴我。`
- **產出物**：hook、口播稿、留言題目、字幕節奏
- **執行提醒**：這支主要任務是收語料，不追求同時拉收藏與追蹤

### Day 4｜低摩擦步驟 Carousel

- **任務**：把抽象的「好好休息」變成今晚真的做得到的切換動作
- **頁數建議**：`5` 頁
- **內容骨架**：封面 -> 常見錯誤 -> 切換概念 -> `3` 個微步驟 -> 收藏 CTA
- **主 CTA**：`今晚想試看看的人，先收藏。`
- **產出物**：步驟頁短文案、順序標題、收尾提醒
- **執行提醒**：步驟只能是低摩擦行為，例如關工作通知、寫下明天第一件事、換居家衣服

### Day 5｜共鳴擴散 Reel

- **任務**：做出最容易被轉傳的一支內容，擴大首週觸及
- **建議 hook**：優先使用 `Hook 12`，備選 `Hook 13`
- **內容骨架**：指出 `休息` 和 `恢復` 的差異 -> 補一句 `常差在有沒有真正退場` -> 分享 CTA
- **主 CTA**：`如果你想到那個下班後還在值班的人，分享給他。`
- **產出物**：分鏡表、對比畫面設計、字幕節奏、收尾 CTA
- **執行提醒**：靠情境對比放大共鳴，不靠恐嚇或誇張式疲勞敘事

### Day 6｜自我檢查 Carousel

- **任務**：讓受眾用一張清單檢查自己有沒有真的慢下來，同時產生留言互動
- **頁數建議**：`4-5` 頁
- **內容骨架**：封面 -> `3` 個檢查點 -> 使用方式 -> 留言 CTA
- **主 CTA**：`你最常卡住的是哪一點？可以留言。`
- **產出物**：檢查點清單、使用說明、留言問題
- **執行提醒**：這是一張自我觀察表，不是診斷表；不做結果保證

### Day 7｜週收束 Reel

- **任務**：把首週訊息收成一條線，讓受眾知道下週會繼續往哪裡走
- **建議 hook**：優先使用 `Hook 15`，備選 `Hook 16`
- **內容骨架**：回顧本週 `3` 個關鍵發現 -> 重新命名疲累感受 -> 預告下週主題
- **主 CTA**：`下週我會繼續拆怎麼讓系統真的退場，想接著看就先追蹤。`
- **產出物**：回顧腳本、封面標題、下週預告句
- **執行提醒**：只留一個下週鉤子，不把週回顧做成導購

## 5. CTA 配置邏輯

- `追蹤` 放 Day 1、Day 7：用於開場與收束，建立系列感與延續期待
- `收藏` 放 Day 2、Day 4：把辨識工具與微步驟沉澱成回看資產
- `留言` 放 Day 3、Day 6：收受眾真實語料，為後續內容校準用詞
- `分享` 放 Day 5：把最強共鳴集中在週五釋放，擴張觸及

## 6. 建議產出順序

| 順序 | 先做什麼 | 目的 |
| --- | --- | --- |
| `1` | Day 1 Reel 腳本與封面 | 先凍結品牌第一句與首週語感，避免後面內容漂移 |
| `2` | Day 2 Carousel 文案與版型 | 優先建立第一份可收藏資產，讓帳號有工具價值 |
| `3` | Day 4 Carousel 微步驟稿 | 先把「一個小步驟」的表達口徑固定下來 |
| `4` | Day 3 Reel 腳本 | 在 Day 1 語感定調後，再做拆誤解內容會更穩 |
| `5` | Day 5 Reel 分鏡與拍攝 | 這支畫面要求最高，需要提早鎖鏡頭與字幕節奏 |
| `6` | Day 6 Carousel 文案 | 可吸收 Day 3 留言語料，讓檢查點更貼近受眾原話 |
| `7` | Day 7 Reel 腳本與錄製 | 最後收斂本週訊息，讓週回顧吃到前面互動成果 |

## 7. 審稿與執行注意事項

- 每篇只保留 `1` 個主結論與 `1` 個主 CTA，不做多目標內容
- 每則 Carousel 儘量控制在 `5-6` 頁內，維持閱讀負擔低
- 所有 CTA 都必須是低壓邀請，不導向私訊成交、限時逼單或錯過焦慮
- 若文案出現 `一定`、`唯一`、`保證改善`、病名化、羞辱式推動，直接退稿
- 所有 Reel 開場都應優先回到 [reel_hook_bank.md](/Users/shock/Projects_local/workspace/mindscape-ai-local-core/reel_hook_bank.md) 取用，不臨場改成更聳動的口氣
- 發文前最後自檢只有四題：有沒有先理解人、是否只講一件事、是否給一個起點、是否維持邊界
