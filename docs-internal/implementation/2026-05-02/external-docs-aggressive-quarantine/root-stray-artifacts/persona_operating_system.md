## 2. 品牌核心一句話

這是一個由創作者本人出鏡的冷靜引導型品牌：把高壓生活裡那些說不清楚的疲累、緊繃與停不下來，翻成受眾聽得懂的人話，並給出今晚就能開始的一個低摩擦起點。

## 3. 品牌北極星

### 3.1 我們為什麼存在

因為很多人不是沒有努力，而是沒有語言理解自己正在經歷什麼。這個品牌存在的任務，不是再多給一套壓力更大的解法，而是先把混亂說清楚，讓人可以從自責退回理解，從理解走到第一步。

### 3.2 我們希望受眾怎麼形容這個品牌

- `這個人懂我現在卡住的狀態。`
- `這個帳號講得清楚，但不會端著專業壓我。`
- `這裡不會叫我瞬間翻身，只會給我一個真的做得到的開始。`
- `我願意追蹤，因為這裡讓我比較不想再怪自己。`

### 3.3 品牌的敵人不是誰

品牌真正對抗的不是某個競品，而是三種受眾每天都在承受的錯誤體驗：

- 把複雜身心狀態講成單一答案。
- 把自我照顧講成新的績效考核。
- 把焦慮當成轉換率工具。

## 4. 角色定位

### 4.1 角色原型

| 項目 | 定義 |
| --- | --- |
| 核心原型 | `科學翻譯型引導者` |
| 外顯形象 | `冷靜的創作者本人`，有方法感，但不擺權威姿態 |
| 心智位置 | 不是來救你的人，而是先把你現在的狀態說清楚的人 |
| 社群關係 | 不是台上訓話，而是站在受眾旁邊一起看懂訊號 |
| 首感印象 | 清楚、節制、穩定、可信 |

### 4.2 角色工作的本質

這個角色不是靠魅力、神秘感或極端故事吸引人，而是靠以下四件事建立黏性：

1. 幫受眾把模糊感受命名。
2. 把複雜機制翻譯成日常語言。
3. 先拆掉自責，再提出一步。
4. 用邊界感換信任，而不是用權威感換服從。

### 4.3 品牌在受眾心中的位置

當受眾出現以下狀態時，這個品牌應該成為第一個被想到的帳號：

- `我知道自己很累，但我講不清楚到底怎麼累。`
- `我已經休息了，為什麼還是沒有恢復感。`
- `我不想再被教更多方法，我只想先搞懂自己卡在哪。`
- `我願意看專業內容，但不想被術語壓住。`

### 4.4 我們是什麼 / 不是什麼

| 我們是什麼 | 我們不是什麼 |
| --- | --- |
| 冷靜的訊號翻譯者 | 診斷者 |
| 有方法感的創作者品牌 | 焦慮型知識帳號 |
| 降低自責的引導者 | 把一切歸因於不夠自律的人 |
| 提供起點的人 | 承諾快速逆轉人生的人 |
| 用邊界換信任的人 | 用危機感換成交的人 |

## 5. 目標受眾

### 5.1 主要受眾輪廓

- `28-45` 歲，高資訊量、高責任感、高自我要求的創作者、知識工作者與自我照顧探索者。
- 習慣扛住事情，也習慣先怪自己。
- 願意聽方法，但討厭被說教。
- 看過很多健康、效率與成長內容，但對過度簡化與情緒操控已經疲乏。
- 對 `可理解、可執行、沒有壓迫感` 的內容反應最高。

### 5.2 常見內在台詞

- `是不是我又不夠自律？`
- `我明明有休息，為什麼還是沒回來？`
- `我知道自己該停，但停不下來。`
- `我不需要再多一套流程，我需要知道我現在怎麼了。`

### 5.3 品牌要承接的核心張力

| 受眾卡點 | 品牌回應 |
| --- | --- |
| 感受很多，但說不清楚 | 先幫他命名 |
| 容易把狀態問題解讀成個人失敗 | 先幫他拆掉自責 |
| 方法太多，反而更難開始 | 只給一個起點 |
| 害怕被推銷、被控制、被教育 | 用低壓 CTA 與清楚邊界說話 |

## 6. 價值主張

### 6.1 對受眾的核心承諾

我們不保證立刻改變你，但會幫你更早看懂自己現在在哪裡，並提供一個不增加壓力的開始方式。

### 6.2 三層價值

| 層次 | 品牌提供的價值 |
| --- | --- |
| 功能價值 | 把複雜身心狀態翻成容易理解的語言、框架與最小步驟 |
| 情緒價值 | 讓人感到被理解、被安定，而不是被催逼 |
| 身分價值 | 讓受眾感覺自己不是失敗，而是終於有語言理解自己 |

### 6.3 為什麼值得追蹤

受眾追蹤這個品牌，不是為了被激勵，而是為了持續得到以下體驗：

- 我可以更早辨識自己的狀態訊號。
- 我可以用更低壓的方式理解疲累、緊繃與停不下來。
- 我每次只會被要求一個小步，而不是一套更重的待辦。
- 我在資訊過載中，有一個穩定、可信、誠實的聲音可回來看。

### 6.4 首週內容承諾

- 每一則內容都先處理 `理解`，再處理 `行動`。
- 每一則內容都只推進 `一個核心觀念`。
- 每一則內容都保留邊界，不講成唯一真相。
- 每一則內容都要讓受眾感到：`今晚我可以先做一點點。`

## 7. 語氣系統

### 7.1 五個語氣支柱

| 支柱 | 受眾感受 | 建議寫法 | 應避免 |
| --- | --- | --- | --- |
| 冷靜 | 被安定 | `先不要急著怪自己。` | `你再不改就會更糟。` |
| 清楚 | 被解釋 | `這可能是一種常見的狀態訊號。` | `這就是唯一答案。` |
| 同理 | 被理解 | `很多人不是不努力，是還沒看懂訊號。` | `你就是不夠自律。` |
| 克制 | 被誠實對待 | `可能`、`有時候`、`未必` | `一定`、`保證`、`所有人都` |
| 有方法感 | 拿到起點 | `今晚先試一個結束訊號。` | `照做就會明顯改善。` |

### 7.2 句型規則

- 優先使用短句，一句只完成一個任務。
- 優先使用人話，不堆砌術語。
- 先講觀察，再講判斷；先講狀態，再講方法。
- 可以溫和，但不能鬆散；可以專業，但不能居高臨下。
- 可以提出方向，但不能替代診斷、治療或結果保證。

### 7.3 語氣轉譯規則

| 原本想寫的方向 | 轉成品牌語氣 |
| --- | --- |
| 警告 | 提醒 |
| 判斷 | 觀察 |
| 命令 | 邀請 |
| 保證 | 起點 |
| 教訓 | 翻譯 |
| 壓力 | 結構 |

### 7.4 關鍵詞庫

**建議多用**

- `訊號`
- `狀態`
- `退場`
- `結束訊號`
- `恢復感`
- `低摩擦`
- `先不用急`
- `先從一個小步開始`

**建議少用**

- `治好`
- `秒懂`
- `逆轉`
- `一定`
- `唯一原因`
- `你就是`
- `不改不行`

## 8. 訊息架構

### 8.1 對外一句話定位

把高壓生活裡那些說不清楚的身心訊號，翻譯成你聽得懂、今晚做得到的一步。

### 8.2 延伸版品牌介紹

這個品牌專注於把日常高壓下的疲累、緊繃、停不下來與恢復不了，拆解成更容易辨識的生活訊號。我們不用恐嚇式說法，也不販售完美解法，而是透過冷靜、清楚、克制的內容，幫受眾先理解，再開始。

### 8.3 標準內容骨架

1. `命中情境`：先說出觀眾正在經歷的畫面或內在台詞。
2. `翻譯機制`：用一句人話解釋可能發生了什麼。
3. `提供一步`：只給一個最低摩擦的動作或觀察角度。
4. `低壓 CTA`：邀請追蹤、收藏、留言或分享，不做壓迫轉換。

### 8.4 每篇內容的完成標準

一篇內容如果沒有同時做到以下四件事，就不算符合品牌 OS：

- 有先接住人，而不是先糾正人。
- 有把抽象感受翻成更清楚的語言。
- 有留下一個真的做得到的下一步。
- 有保留不過度承諾的邊界。

## 9. 執行規格

### 9.1 鏡頭中的角色狀態

創作者本人出鏡時，角色感應維持以下方向：

- 眼神穩定，不表演驚嚇式震撼。
- 節奏偏穩，不用高壓推進口氣。
- 手勢與表情以 `說清楚` 為主，不以 `煽動` 為主。
- 像一個已經整理好思路、正在把複雜事講明白的人。

### 9.2 內容決策原則

- 如果一則內容能讓人感覺自己被理解，它才值得發布。
- 如果一則內容只是看起來聰明，卻不能讓人更容易開始，不值得發布。
- 如果一則內容必須靠誇大、危機或羞辱才能成立，不能發布。
- 如果一則內容會讓受眾覺得自己又多了一份待辦，必須重寫。

### 9.3 CTA 原則

- `追蹤` 用在建立系列感與延續期待。
- `收藏` 用在工具、清單、步驟與辨識框架。
- `留言` 用在蒐集受眾原話與卡點。
- `分享` 用在高共鳴、可被轉傳的情境對比。

補充：CTA 是邀請，不是施壓。任何 `不做就來不及`、`現在不改會更糟` 類型話術都不屬於此品牌。

## 10. 品牌紅線

### 10.1 內容紅線

- 不把單一症狀、情緒或疲累感直接等同於醫療診斷。
- 不宣稱療效、治癒、保證改善、快速逆轉。
- 不把複雜身心議題講成單一原因。
- 不拿創傷、脆弱經驗做戲劇化消費。
- 不用恐嚇、羞辱、否定人格的方式製造互動。

### 10.2 語言紅線

- 禁止使用 `你一定有問題`、`你就是不夠自律`、`再不改就會更糟` 這類判決式句型。
- 禁止使用 `唯一原因`、`保證有效`、`所有人都適用` 這類絕對化措辭。
- 禁止把專業名詞當作權威工具，用來壓住受眾提問。
- 禁止用假性關心包裝真實的焦慮導流。

### 10.3 商業紅線

- 首週內容不以硬轉換為主，不急著推銷高單價服務。
- 不透過危機感逼迫私訊。
- 不用 `限時不做就來不及` 這類高壓銷售話術。
- 商業導向內容也必須先有真實內容價值，再提出邀請。

### 10.4 社群互動紅線

- 留言回覆先接住，再補充，不先糾正。
- 面對不同經驗時，使用 `也可能`、`未必一樣` 保留個體差異。
- 遇到明顯涉及醫療、危機、診斷需求時，不自行判讀，應引導尋求合適專業協助。

## 11. 審稿檢核

任何首週內容在發布前，都應通過以下問題：

1. 這則內容有先讓人感到被理解嗎？
2. 這則內容有把複雜感受翻成更清楚的人話嗎？
3. 這則內容只要求一個小步，而不是丟出更多待辦嗎？
4. 這則內容有保留 `可能`、`有時候`、`未必` 這類誠實邊界嗎？
5. 這則內容有沒有任何恐嚇、絕對化、過度承諾或羞辱成分？

只要第 `5` 題答案不是明確的 `沒有`，就不應發布。

## 12. 可直接套用的品牌語句

### 12.1 建議句型

- `你不是不會休息，你可能只是還沒收到退場訊號。`
- `很多人不是不努力，是一直沒有真正結束今天。`
- `先不用急著怪自己，這有時候只是系統還沒切回來。`
- `如果你最近也有這種感覺，可以先從一個小步開始。`
- `休息不一定等於恢復，差別常在有沒有真的退場。`

### 12.2 禁用句型

- `你一定是自律神經失調。`
- `照著做，今晚就會明顯有感。`
- `這就是你一直累的真正原因。`
- `你停不下來就是因為你不夠自律。`
- `再不調整，之後只會更糟。`

## 13. 總結

這個品牌的 operating system，不是建立在更強、更快、更厲害，而是建立在 `更清楚、更節制、更可信`。首週 Instagram 的任務不是證明品牌多專業，而是讓受眾在第一次接觸時，立刻感覺到三件事：

- 這個人懂我現在說不清楚的狀態。
- 這個帳號不會拿我的焦慮來成交。
- 我願意繼續看下去，因為這裡真的有一種比較低壓的開始方式。
