# Mindscape AI Local Core Documentation

This public documentation area covers installation, local startup, and released architecture boundary material for external readers.

Public pages describe stable Local Core behavior first: what the local runtime owns, how readers interact with it, and which repository landmarks back the claim. Owner-specific implementation notes, operational records, and contributor-only material stay in their owning records until they are rewritten as stable external documentation.

## Current Structure

The public set is focused:

- `getting-started/` covers installation, Docker startup, platform notes, and troubleshooting.
- `architecture/` covers released Local Core architecture boundaries and source landmarks.
